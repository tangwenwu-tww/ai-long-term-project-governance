# T-GO-001：建立正式 Go 源码骨架

## 用途

根版本控制基线通过独立审查后执行本任务。目标是得到一个可构建、可测试、目录职责清楚的 Go CLI 空壳，为后续 contract tests 提供入口；本任务不实现治理实例安装、校验、状态机、信任或升级逻辑。

## 任务契约

```yaml
task_id: T-GO-001
title: 建立正式 Go canonical source 与最小 CLI 测试入口
phase: 0
acceptance_criteria:
  - 正式源码位于独立 tool/ 目录，不复制或改写 Python PoC 与 experiments
  - tool/go.mod 可被 Go 1.27 解析，且不引入第三方依赖
  - CLI 只提供 help、version 与未知命令处理，不实现任何治理业务命令
  - help 和 version 返回 0，未知命令返回非 0，stdout/stderr 行为有自动测试
  - go test ./...、go vet ./... 与 go build ./cmd/aigov 均退出 0
  - 构建产物写入被忽略的输出目录，不进入 Git
  - README 能让新 Agent 独立复制构建、测试和运行命令，并说明本任务未实现的能力
  - changed_files 全部位于 allowed_files，根仓库在提交后 clean
allowed_files:
  - tool/go.mod
  - tool/README.md
  - tool/cmd/aigov/main.go
  - tool/internal/cli/run.go
  - tool/internal/cli/run_test.go
  - docs/正式项目接入/14-Go正式源码骨架任务单.md
  - .git/
pre_implementation_search:
  commands:
    - rg -n 'package main|func main|plan|apply|doctor|version|help' experiments poc docs/正式项目接入
    - rg --files -g 'go.mod' -g '*.go' .
  evidence_required: 列出既有 Go 实验文件并说明为何只参考交付证据、不直接复制为正式产品源码
doc_type: how-to
doc_purpose: 说明正式 Go CLI 骨架如何构建、测试和运行，以及当前明确未实现的能力
```

## 最小目录边界

```text
tool/
├─ go.mod
├─ README.md
├─ cmd/aigov/main.go
└─ internal/cli/
   ├─ run.go
   └─ run_test.go
```

- `cmd/aigov/main.go` 只负责进程入口和退出码，不承载可复用逻辑。
- `internal/cli/run.go` 只解析 `help`、`version` 和未知命令，以便不启动子进程即可测试 I/O 与退出码。
- 当前 module path 是内部可执行工具的构建标识，不作为外部 Go API 稳定性承诺；仓库远端与发布路径确定后再单独评估是否调整。
- Go 1.27 是首轮构建基线，不等于已经冻结最低兼容版本；最低版本必须由后续兼容实验决定。

## 明确禁止

- 不得从 `poc/` 复制 Python 行为后逐行翻译。
- 不得新增 `plan`、`apply`、`doctor`、`upgrade`、状态机、JCS、Ed25519 或文件写入逻辑。
- 不得为了未来功能预建多层接口、插件系统、依赖注入容器或第三方 CLI 框架。
- 不得修改根方法论文档来迁就代码实现；契约冲突时停止并报告。

## 验证命令

在 `tool/` 目录执行：

```powershell
go test ./...
go vet ./...
go build -o ../out/aigov.exe ./cmd/aigov
../out/aigov.exe help
../out/aigov.exe version
../out/aigov.exe unsupported
```

最后一条命令预期为非零退出码；其余命令预期为 0。若系统没有全局 Go，可使用任务目录外或已被忽略目录中的官方便携工具链，禁止把工具链纳入仓库。

## 常见错误 / 注意事项

- CLI 空壳通过不代表安装器、自动校验器或状态机已经完成。
- 不要把实验目录的 `main.go` 直接复制过来；它只证明跨平台交付可行。
- 不要因本机缺少全局 Go 要求项目负责人手工安装；Executor 可使用隔离便携工具链完成验证。

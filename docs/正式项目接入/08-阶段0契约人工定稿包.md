## 人工需要确认的五个问题

### 1. 安装器究竟生成什么？

生成项目专属治理实例，而不是复制整套方法论：项目 Agent 入口、实例 manifest、阶段/策略派生缓存、版本化 schemas/runtime、任务/证据/审查/事件存储，以及按生命周期条件创建的项目文档。

### 2. 哪些内容绝不能被上游覆盖？

`AGENTS.md` 中的项目事实、已经存在的 `DESIGN.md`、`docs/decisions.md`、项目 ADR、人工 trust anchors 与项目产生的任务/证据/审查历史。升级只能提供三方差异或 migration plan。

### 3. 新 Agent 如何只依赖目标仓库运行？

目标仓库保存唯一启动入口、固定版本的本地运行时/schema、当前阶段与任务契约。基本 inspect/validate/gate 不依赖方法论源仓库、全局 CLI 或联网。

### 4. 如何升级、回滚和验证身份？

升级先生成 plan，保护项目事实并记录文件清单/哈希；apply 失败恢复到写入前。阶段与 trust 以不可变事件链为权威源，缓存可重建；身份来自编排器、CI 或外部签名批准，Agent 自报只能降级为 declarative。

### 5. 本次冻结是否等于技术选型？

否。契约只定义稳定语义，不决定 Go、Node、Python 或其他语言。技术栈必须在三平台实验、签名、升级/回滚和目标项目安装实验完成后另行批准，并写入 `docs/decisions.md`。

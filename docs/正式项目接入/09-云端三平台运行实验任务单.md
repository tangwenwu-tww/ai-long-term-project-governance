## 停止条件

- 云端上传集合包含 `experiments/cloud-runtime-matrix/` 之外的项目文件时，停止推送。
- 同一 failure signature 连续三次时停止并升级人工，不通过反复改参数掩盖。
- 工作流要求创建长期凭证、公开仓库或修改正式治理契约时，停止并另行授权。
- 若需要创建 `docs/decisions.md`、根 `.git` 或正式产品骨架，立即停止。

## 不证明什么

- 不证明安装、升级、回滚、代码签名发布或目标项目接入已经实现。
- 不证明 Node SEA 与 Go 的最终选型优劣；结果只是后续人工选型输入。
- GitHub 托管 runner 的成功不等于所有用户机器、所有 CPU 架构或离线环境均可运行。

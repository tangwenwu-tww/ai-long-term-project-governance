## 与本地实验的差异

Node SEA 的三个云端产物大小与 Windows 主机交叉生成实验一致，但 SHA-256 不同。相同 Node 版本与源码不保证跨主机产物字节可重现，因此每次 CI 的哈希只能作为该次运行证据，不能直接当成永久发布摘要。

Go 的 SHA-256 在不同云端 commit 的成功运行间也发生变化；`go build` 默认嵌入 VCS 修订信息，commit 改变即可改变产物字节。若后续要求可重现构建，需要另设任务验证 `-buildvcs=false`、构建环境固定与供应链声明，不能从本实验的绿色结果反推可重现性。

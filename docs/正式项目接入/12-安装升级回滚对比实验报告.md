# 安装、升级与回滚对比实验报告

## 当前状态

独立 Reviewer 首轮发现 `doctor` 未检查 manifest 版本与受管 payload 的一致性；实现和黑盒测试修正后三平台重新运行通过，第二轮独立复核结论为 PASS（Critical 0 / Major 0 / Minor 0）。本报告现为 `active`，可作为阶段 0 最终选型的证据输入，但仍不是正式安装器实现依据。

## 成功标准

以 [T-DELIVERY-005 任务单](./11-安装升级回滚对比实验任务单.md) 的九项验收标准为唯一判定依据。两个候选必须运行同一黑盒测试，不能用不同测试降低某一候选门槛。

## 结果

GitHub Actions 修正版运行：[Installer lifecycle matrix #4](https://github.com/tangwenwu-tww/ai-governance-installer-lifecycle-matrix/actions/runs/45414531366)

- 被测提交：`6cd040cbca2e6bf0ecee27ed8318ffcc7d198752`
- 工作流结论：第一次尝试中 Windows、Linux 成功，macOS 因 GitHub hosted runner 未被分配而发生平台内部错误；只重跑失败 job 后 macOS 成功，最终页面为 3/3 jobs 成功。
- 黑盒矩阵：Go 与 Node SEA 各自在三个平台运行相同测试，共 6/6 组合通过；每个组合均为 9/9 checks。
- 统一的 v0 runtime SHA-256：`547bb5f600c6dfb039a5426d587ff433cabb3937426908a62e46dec239912883`。

| 平台 | Go | Node SEA | 结论 |
|---|---:|---:|---|
| Windows x64 | 9/9 PASS | 9/9 PASS | 同一生命周期契约通过 |
| Linux x64 | 9/9 PASS | 9/9 PASS | 同一生命周期契约通过 |
| macOS arm64 | 9/9 PASS | 9/9 PASS | 同一生命周期契约通过 |

覆盖的公开行为为：`plan` 不写盘、首次 `apply`、二次 `apply` 字节幂等、保留既有 `AGENTS.md`、v0→v1 `upgrade`、本地冲突停止、精确 `rollback`、`doctor` 发现文件哈希漂移，以及 `doctor` 发现 manifest 版本与受管 payload 不一致。测试只通过候选 CLI 执行，没有导入候选内部函数。

## 产物体积与构建复杂度

| 平台 | Go 产物 | Node SEA 产物 | Node / Go |
|---|---:|---:|---:|
| Windows x64 | 2,984,448 B | 100,240,200 B | 33.6× |
| Linux x64 | 2,883,744 B | 150,703,232 B | 52.3× |
| macOS arm64 | 2,732,082 B | 145,415,332 B | 53.2× |

- Go：`go build -trimpath -ldflags='-s -w'`，单一标准工具链命令，无运行时文件拼装。
- Node SEA：`node --build-sea <config>`，同样不引入第三方包，但构建依赖平台对应的 Node 版本和 SEA 配置文件，产物包含 Node 运行时。
- 两个候选的协议实现均未引入第三方运行时依赖；差异主要来自交付体积与运行时承载方式，而不是本轮功能行为。

## 签名与发布边界

- Windows：Go 与 Node SEA 均为 `NotSigned`。
- Linux：代码签名不适用，记录为 `not-applicable`。
- macOS：Go 为链接器产生的 ad hoc 签名，没有 TeamIdentifier；Node SEA 为 `code object is not signed at all`。

因此本实验没有证明可信发布、Windows SmartScreen 放行、Apple Developer ID 签名或 notarization。不得把 ad hoc 或未签名结果描述为正式签名通过。

## 选型边界

本实验消除了两个候选在安装生命周期行为上的不确定性：两者都能满足当前黑盒契约。它同时给出明显的交付差异：Node SEA 产物约为 Go 的 33.6–53.2 倍，构建还需维护平台对应的 Node SEA 配置；Go 的交付面更小。

项目负责人已于 2026-11-24 基于本报告和三平台运行证据选择 Go 作为正式工具层载体。权威决定、排除理由、已接受风险和推翻条件见 [`docs/decisions.md`](../decisions.md)；本报告继续只承担实验事实，不替代决策记录。

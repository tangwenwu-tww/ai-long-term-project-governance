# T-DELIVERY-003：交付运行时实验任务单

## 任务边界

本任务只验证候选运行时的自包含、跨平台构建入口、标准密码能力与产物可审计性。实验不实现安装、升级、状态机或业务功能，也不形成正式技术决策。

```yaml
task_id: T-DELIVERY-003
phase: 0
title: 验证 Go 原生二进制与 Node SEA 的最小交付能力
acceptance_criteria:
  - Windows amd64 的 Go 产物可在不依赖 go 命令的子进程环境直接运行
  - Windows x64 的 Node SEA 产物可在不依赖 node 命令的子进程环境直接运行
  - 两个产物对同一事件字节计算相同 SHA-256，并验证同一个 Ed25519 trust 签名
  - 尝试构建 Linux amd64 与 macOS arm64 产物；未在对应系统实际执行时必须标记为未验证
  - 记录工具链来源、版本、下载校验和、构建命令、退出码、产物大小与 SHA-256
  - 明确实验不能证明 JCS 实现、代码签名、升级/回滚或三平台实际运行
allowed_files:
  - experiments/delivery-runtime/**
  - docs/正式项目接入/07-交付运行时实验报告.md
pre_implementation_search:
  commands:
    - rg -n "zipapp|SEA|Go 原生|交付方式|Ed25519|JCS" docs/正式项目接入
  evidence_required: 说明与 03 契约、04 选型任务书及 Python PoC 的关系
```

## 停止条件

- 下载文件哈希与官方清单不符时立即停止使用该工具链。
- 同一 failure signature 连续三次时停止并记录，不通过更换参数掩盖。
- 实验若需要修改 `03`、`04` 或创建 `docs/decisions.md`，立即停止并另行申请范围。

实验报告通过独立审查后，本任务完成；正式选型仍需完成三平台运行、签名发布、升级/回滚和目标项目安装实验。

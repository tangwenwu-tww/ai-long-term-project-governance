## Major findings

### M-R2-1 审计哈希链没有冻结可跨实现重算的字节契约

- **位置**：`03-治理实例规范v0.md:254-260, 306-325`
- **风险**：规范要求 `prev_event_sha256` 和事件哈希链，却没有定义哈希输入是原始 JSONL 行、去掉哪个哈希字段后的对象、JCS 字节还是其他序列化，也没有规定 UTF-8/BOM、换行和数值/时间表示。Python、Node、Go 即使拥有相同逻辑事件，也会生成不同字节和哈希，导致事件重放、并发校验、迁移与跨环境审计互不兼容。这是持久化公共契约，留到实现时决定会形成高返工迁移。
- **修复**：明确 `event_sha256` 的字段集合和排除字段；规定使用 JCS 或另一种唯一规范化算法、UTF-8 无 BOM、是否包含换行；把哈希值写入事件或明确定义下一事件如何引用；给出连续两条事件的完整输入、规范化字节/十六进制和期望 SHA-256 测试向量。
- **验证**：分别用至少两种语言仅依据文档计算测试向量，两个 `event_sha256` 与规范值完全一致；修改任一受保护字段必须使第二条事件验证失败。

### M-R2-2 Trust 初始化/轮换/撤销仍缺少稳定事件信封与原子提交协议

- **位置**：`03-治理实例规范v0.md:200, 364-420`
- **风险**：批准信封已经明确为单个 `signature` 的 `ed25519-jcs-v1`，但 `TRUST_ROTATE` 要求 current key 与 recovery key 双签时，没有定义双签字段结构、各签名覆盖的确切 payload、key ID 绑定和稳定错误码；`TRUST_INIT`/`TRUST_REVOKE` 也没有完整事件样例。初始化描述为写 `trust.json`，恢复又依赖 phase audit 中的初始化事件，却未规定两者的写入顺序、锁、失败回滚及哪一个先成为有效状态。不同实现仍可能生成无法互验或无法恢复的 trust 历史。
- **修复**：为 `TRUST_INIT`、`TRUST_ROTATE`、`TRUST_REVOKE` 各给完整 JSON 信封和 schema；定义双签数组顺序或按 key ID 排序规则、每个签名的 JCS payload、用途约束与错误码；规定在 `phase_audit_log` 单写锁内的准备、事件原子追加、`trust.json` 缓存重建顺序，明确崩溃发生在每一步时如何恢复。`trust.json` 应继续是可重建缓存，不能先写成新的权威状态。
- **验证**：提供初始化、正常轮换、缺一签名、签名顺序交换、撤销、事件成功但缓存重建前崩溃六组测试向量；两个独立实现应得出相同 trust 状态和错误码。

## Minor findings

### m-R2-1 manifest 仍有两个非确定性/不可复制细节

- **位置**：`03-治理实例规范v0.md:127, 144-145`
- **问题**：`phase_basis.assessed_at` 以“允许时钟偏差”作为拒绝条件，但没有指出该偏差来自哪个固定值或字段；`selection_record.sha256` 的示例 `0123…cdef` 不是可复制的 64 位小写十六进制值。
- **修复**：为 phase assessment 指定固定 v0 偏差或明确引用哪个配置字段；把 SHA 示例换成真实 64 位值，并增加 `selection_finalized=true` 的完整有效片段。
- **验证**：同一未来时间样例在两个实现中得到相同结果，复制 SHA 示例可通过 schema。

### m-R2-2 逻辑资源映射未覆盖所有宣称可调整的物理资源

- **位置**：`03-治理实例规范v0.md:41-76, 169-172`
- **问题**：逻辑 ID 表覆盖主要 task/evidence/review/audit 资源，但 `design_spec` 已出现在 plan 输出中却没有映射；`instance`、runtime/schema、maturity facts/cache、policy cache 和 task state 也没有逻辑 ID。规范同时声明公共 API 不承诺物理路径、改变目录只能改变映射，当前表无法兑现这一声明。
- **修复**：补齐所有可由命令引用或允许改目录的资源 ID；或者明确列出固定不可映射的内部资源，并禁止外部 API 输出它们的物理路径。plan 的 `design_spec` 必须能解析到稳定逻辑资源。
- **验证**：为 default/custom 两套布局列出完整资源表；对相同操作序列，所有外部输出只出现逻辑 ID，结果等价。

# 文档 11：`DESIGN.md` 模板（前端项目交互与视觉事实规范）

> 用法：有前端页面的项目，把本项目散落的颜色、间距、通用组件和既定交互，按这份模板梳理进根目录 `DESIGN.md`。**它是「既定事实」，每个前端任务会话开始前必须完整读取；后续 AI 只能在里面复用，不能默认推翻。**
> 为什么需要它、怎么和 UI skill 互补，见[文档 10：前端 UI 方法论](./10-前端UI方法论.md)。

> 复制以下内容到项目根目录 `DESIGN.md`，按本项目替换方括号内容。**每个涉及前端的 AI 会话开工前必须先读本文件。**

```markdown
# DESIGN.md — 本前端项目的交互与视觉事实规范

> 本文件是**既定事实**，不是建议。前端任务开工前必须读。不能复用的必须说明理由并经人工批准。改动本文件 = 改变交互/视觉基线，须记录到更新记录。

## 1. 设计北极星（一句话）
[本项目界面一眼要让人记住什么。例如：冷静的财务工作台，所有数据都清晰可扫，不追求花哨。]

## 2. 色彩令牌（Color Tokens）
> 所有颜色必须从这里取，禁止在组件里硬编码色值。加新色先在此登记并给理由。

| Token | 值 | 用途 | 示例 |
| --- | --- | --- | --- |
| `color.primary` | `#2563EB` | 主操作、选中态 | 主按钮背景 |
| `color.bg` | `#FFFFFF` | 页面底色 | 卡片外背景 |
| `color.surface` | `#F9FAFB` | 卡片/面板底色 | 筛选面板 |
| `color.text.primary` | `#111827` | 正文、标题 | 列表标题 |
| `color.border` | `#E5E7EB` | 分隔线、描边 | 表格描边 |
| `color.danger` | `#DC2626` | 错误、删除、破坏性操作 | 删除确认 |

## 3. 间距与圆角令牌（Spacing & Radius）
> 禁止散落魔法数字。间距、圆角、字号都要在这里取。

| Token | 值 | 用途 |
| --- | --- | --- |
| `space.1` | 4px | 图标内/紧凑间距 |
| `space.2` | 8px | 相邻元素间距 |
| `space.3` | 16px | 卡片内 padding |
| `space.4` | 24px | 区块间距 |
| `radius.md` | 8px | 卡片圆角 |
| `radius.full` | 999px | 标签/胶囊 |

## 4. 通用组件清单（必须复用）
> 新增任何功能前，先在这里找已存在的组件；找到就必须复用，找不到才新建。

| 组件 | 位置 | 用法要点 | 禁止事项 |
| --- | --- | --- | --- |
| `Button` | `components/ui/button` | 主操作用 `variant="primary"` | 禁止自行造按钮样式 |
| `Card` | `components/ui/card` | 容器、选项卡片 | 卡片选中交互必须走 `selectable`，禁止改成下拉 |
| `Select` | `components/ui/select` | 下拉选择 | 仅在「条目多、需搜索」时用 |
| `DatePicker` | `components/ui/date` | 日期输入 | 禁止裸调 `new Date()` |
| `Modal` | `components/ui/modal` | 弹层 | 确认类统一用它 |

## 5. 既定交互基线（Blacklist / 不可默认推翻）
> 这是**交互黑名单**。下面的交互是产品决意，后续 AI 不许凭「通用常识」擅自改写；想改必须说明理由并经人工批准。

| 场景 | 既定交互 | 为什么这么定 | 禁止改成 |
| --- | --- | --- | --- |
| 选项选择（≤ 5 项） | **卡片单选**（点卡片即选中，高亮描边） | 信息密度低、可一次看全，符合财务工作台风格 | 下拉选择器 |
| 表单提交失败 | 保留已填内容 + 顶部错误条 | 避免用户重填、错误可扫 | 清空表单 / 只弹窗 |
| 删除操作 | 进弹窗二次确认 | 破坏性操作需确认 | 直接删除 |
| 列表加载 | 骨架屏 | 减少跳动、体感更快 | 全屏 loading |

## 6. 复用强制规则（写入 AGENTS 行为规则）
- 新增功能前必须先检索 `components/` 与 `lib/`（见任务单 `pre_implementation_search`），确认是否有可复用组件/函数。
- 新增了 `lib/`/`components/` 已存在的等价实现 → 审查判为 `DUPLICATE_LOGIC`，阻断合并。
- 关键逻辑禁止写死在 UI 层；请求禁止在组件内直接写，必须走 `api/` 层。

## 7. 更新记录
| 日期 | 改了什么 | 批准 |
| --- | --- | --- |
| YYYY-MM-DD | 初版：固化色彩、间距、组件、交互基线 | 人工 |
```
